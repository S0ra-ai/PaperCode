TUI / Models

中文 TUI 与模型工作台

TUI 是主产品界面。模型工作台负责注册 provider、缓存模型、选择候选池、主/备用决策模型和阶段策略。

TUI 修改入口

路径职责
routes/home.tsx首页输入、PaperRun 创建、深度档位、目录展示。
routes/paper-models.tsx/models 全屏模型工作台。
routes/paper-folder.tsx工作目录选择与回退 TUI picker。
routes/paper/index.tsxPaperRun dashboard、右侧栏、Preview/Export 控制。
component/error-component.tsx中文 fatal/error 诊断页。
paper-visible-commands.ts用户可见命令白名单。

模型库存语义

  • provider_registrations：用户真实注册的 provider。订阅型必须 auth 成功，自定义型必须保存 endpoint。
  • candidates：已注册 provider 刷新得到的所有模型。
  • allowlist：用户允许 PaperRun 和 Agent Team 使用的唯一模型池。
  • decision_model / backup_decision_model：从 allowlist 中选择。
  • stage_model_policies：每个阶段支持自动、动态、强制指定。

Provider 注册

ChatGPT 订阅

通过 auth 登录，同步可用模型到 openai/*。

GitHub Copilot

通过 auth 登录，同步可用模型到 github-copilot/*。

自定义 endpoint

填写 base_url/api_key，调用 /models，默认启用发现到的全部模型。

测试重点

  • 无模型时首页不得显示默认模型，只引导进入 /models。
  • 候选模型不等于可用模型；只有 allowlist 可路由。
  • 刷新 provider 后首页必须立即反映主模型和可用模型数量。
  • 新 provider 默认启用全部发现模型，但用户可以批量取消。
