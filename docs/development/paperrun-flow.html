PaperRun

运行流程与状态

PaperRun 将输入、计划、证据、实验、写作、审查和导出串成可恢复、可审计的论文生产链。

代码/实验型论文的证据链

  1. intake 通过 material-index.ts 扫描代码、论文材料、数据和实验日志，写入 sources.jsonl。
  2. code_analysis 通过 code-to-paper.ts 生成 CodebaseMap、MethodExtraction、ExperimentSurface、ReproductionPlan。
  3. claim_ledger 将本地代码 source range 转为可验证 SourceRecord，绑定到 method claim。
  4. experiment_execution 与 reproduction 读取 ExperimentEvidenceManifest.v1 或运行工具链。
  5. verification 检查 claim/source/citation/license/reproduction；失败时 final export 阻断。
