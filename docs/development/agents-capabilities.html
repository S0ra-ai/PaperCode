Agent Fabric

递归 Agent 与能力总线

Agent Team 没有产品硬上限。扩展由预算、时间、并发、权限、上下文、完成度和真实性 gate 共同约束。

模块入口

模块职责
agent-team.tsAgent Team 角色、子 agent、深度、预算、状态和证据合并。
agents.tsAgent node、tree、状态事件。
model-router.ts根据角色、预算、能力、隐私策略选择模型。
capability-pack.ts内置能力包：论文 profile、文献、crawler、HF、代码实验、写作审查导出。
capability-registry.ts统一注册 skill、MCP、builtin tool、Python tool。

权限与证据规则

  • 子 agent 的权限只能比父 agent 更窄。
  • 模型必须从 allowlist 经路由选择，不能直接绕过。
  • 数据外传要写入 audit/tool trace；敏感路径默认阻断。
  • 代码结论必须带 source range；无来源内容不能进入 ClaimLedger。
  • 实验 claim 只能引用复现通过或明确标记 exploratory 的结果。
  • 未授权网络访问时，crawler、Hugging Face、provider 和 benchmark 都必须返回 blocked diagnostic，不能合成来源、模型、数据或实验记录。
  • 测试记录必须走显式测试开关，例如 test_records + allow_test_records；真实产物不得携带测试来源、伪容器镜像或伪 digest。
