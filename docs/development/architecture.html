Architecture

架构边界

Paper Fucker 是论文领域系统。模型、工具、会话、MCP、skills 和 TUI runtime 是底层能力；论文状态和真实性 gate 属于 Paper Fucker。

主要目录

路径职责修改时注意
packages/opencode/src/paper论文领域内核：PaperRun、orchestrator、模型路由、Agent、capability、Preview/export 绑定。新增领域行为优先放这里。
packages/opencode/src/cli/cmd/tui中文 TUI 工作台、命令面、模型工作台、目录选择、PaperRun dashboard。用户可见文案、快捷键和布局都要在这里验收。
packages/preview只读实时 Web Monitor。SSE snapshot 字段变更要同步协议和前端。
research-toolsPython 工具、MCP bridge、数据/实验辅助。涉及外部依赖时必须有 blocked diagnostic。
schemas研究事实契约。schema 变更要同步 TypeScript/Pydantic 类型和测试。

实现边界

  • PaperRun 是一等状态，不是普通聊天 session 的别名。
  • 论文领域 artifacts、gate、source ledger 和 export bundle 由 Paper Core 管。
  • Provider/model 只能通过 Paper 模型库存、allowlist 和路由进入 Agent Team。
  • 用户目录、运行历史和密钥状态均使用 Paper Fucker 自有路径。
