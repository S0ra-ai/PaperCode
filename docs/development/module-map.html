状态与文件

本机状态~/.paper_fucker/model-inventory.json 保存 provider/model allowlist；~/.paper_fucker/runs 保存运行历史、artifacts、exports。
运行事实run.json 是 run 元信息；events.jsonl、sources.jsonl、claims.jsonl、artifacts.jsonl 是事实日志；index.sqlite 是重建索引。
导出文件exports/<bundle-id> 写 Markdown、LaTeX、PDF、DOCX 和 manifest；final 与 forced draft 必须能从 manifest 追溯。
实时监控PreviewSnapshot.v1 是 Web Monitor 和 TUI dashboard 的共同数据面，新增字段必须保持向后兼容。

TUI / CLI
  -> HTTP API handlers
    -> Paper Core run.ts
      -> orchestrator.ts
        -> research/source, code-to-paper, experiments, writing, verification
      -> run-store + artifact-store
      -> preview/export
  -> Preview Web Monitor reads snapshot/SSE
  -> reports/tests validate output

维护规则

  • 新增用户可见能力，至少要改 TUI、HTTP API、Paper Core、测试和开发手册。
  • 新增研究事实，必须有 schema 名、artifact 写入、snapshot 暴露和回归测试。
  • 新增实验能力，必须明确 host/container、失败类别、stdout/stderr 存放和 final gate 影响。
  • 新增模型能力，必须通过 PaperModelInventory、allowlist 和 routePaperModel，不能绕过用户选择。
