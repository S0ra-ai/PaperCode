接口、事件和数据契约

本页记录 TUI、HTTP API、Paper Core、Preview 和 export 之间的稳定边界。改运行链路时先改契约，再改实现和测试。

契约分层

TUI Intent HTTP Payload PaperRun Fact Artifact Schema Snapshot Export Manifest

每层只承担自己的责任。TUI 不直接拼 artifact；Preview 不读取任意本机文件；export 不绕过 final gate；Agent 和实验 runner 只写结构化事实。

HTTP API 入口

接口输入输出维护规则
POST /paper/runs主题、工作区、材料路径、研究深度、期刊 profile、模型策略。PaperRunCreated 或结构化错误。必须携带当前工作区；无可用模型时返回中文 blocked diagnostic。
GET /paper/runs/:idrun id。run 摘要、stage graph、diagnostics、export state。用于恢复和 TUI dashboard；不能要求重新执行。
GET /paper/runs/:id/eventsrun id 和 SSE token。paper.run.snapshot 与增量事件。新增事件必须可被老客户端忽略；snapshot 是权威 UI 数据面。
POST /paper/runs/:id/controlpause、resume、stop、rerun_experiment。控制结果和最新 snapshot。控制动作必须写入事件流，便于恢复和审计。
POST /paper/runs/:id/export格式、profile、是否 forced draft。bundle id、文件清单、manifest。final export 必须先通过 gate；forced draft 不能伪装成 final。
GET /paper/providers/discoverprovider 注册状态。已注册 provider、候选模型、allowlist、smoke 状态。只返回用户已注册 provider 的模型；未注册 provider 只能作为注册模板。
GET/PUT /paper/model-roles主/备用决策模型、候选池、阶段策略。PaperModelInventory。主/备用模型只能来自候选池；阶段模型支持自动、动态和强制指定。

结构化错误

所有用户可见错误都应返回可操作结构，而不是裸异常、schema 栈或内部 tag。

{
  "code": "paper_run_creation_failed",
  "message": "PaperRun 创建失败：缺少可用模型。",
  "action": "打开 /models 注册 provider，并选择候选模型和主决策模型。",
  "log_path": "C:\\Users\\...\\.paper_fucker\\data\\log"
}
  • code 用于测试和日志检索，保持英文稳定。
  • message 面向用户，必须是中文。
  • action 给出下一步，不重复堆栈。
  • log_path 只给目录或相对 run 路径，不暴露 secret。

PaperRun 事实日志

文件内容写入者读者
run.jsonrun 元信息、工作区、状态、创建时间、profile。createPaperRunTUI、history、resume。
events.jsonlstage、model、agent、preview、export、control 事件。orchestrator、controller、export。SSE、diagnostics、reports。
sources.jsonl论文材料、代码 source range、数据、日志、文献来源。intake、code analysis、literature。ClaimLedger、draft、verification。

artifacts.jsonl每个 artifact 的 schema、路径、source_ids、stage。所有 stage handler。Preview、export、strict acceptance。

事件命名

事件触发时机必须携带
paper.run.snapshotrun 创建、stage 更新、draft/export/diagnostic 变化。snapshot version、run id、stage summary、gate summary。
stage.updatedstage queued/running/blocked/completed。stage id、status、started/completed timestamp。
model.routing_decisionAgent 或 stage 选择模型。stage、candidate set、selected model、reason、override source。
experiment.command.started受控命令执行前。command id、role、environment、cwd、timeout。
experiment.command.completed受控命令结束。exit code、duration、stdout/stderr artifact id、metrics。
gate.summary_updatedverification 或 export 前后。passed、failed checks、warnings、action。
preview.updatedsnapshot 进入 Preview render queue。preview URL、token scope、snapshot revision。

Preview Snapshot

PreviewSnapshot.v1 是 TUI dashboard 和 Web Monitor 的共同数据面。新增字段先在 snapshot 中稳定，再由前端渲染。

字段来源约束
stagesstage graph 和 events。顺序稳定，状态可枚举。
draftDraftPaper.v1。无真实草稿时显示空状态，不渲染占位正文。
sources / claimssource/claim ledger。只展示摘要，完整证据留在 bundle manifest。
experimentsprotocol、runs、terminal traces、result report。必须能看见命令、状态、指标和 stdout/stderr 摘要。
machine_environment机器环境探测 artifact。展示 GPU/CPU、runtime/compiler、容器能力和阻断缺失。
export_stateexport facts 和 gate。final、forced、blocked 三种语义不能混用。

修改检查清单

  • 改 payload：同步 HTTP handler、TUI 调用、schema 测试和结构化错误。
  • 改 artifact：同步 schema 名、artifact store、snapshot、export manifest 和 strict acceptance。
  • 改 event：同步 SSE、Preview render queue、TUI subscription 和 browser smoke。
  • 改 export：同步 final gate、forced draft 语义、manifest 和 PDF/DOCX 验收。
  • 改模型：同步 provider 注册、allowlist、主/备用模型、阶段策略和 routing diagnostics。
