Usage Guide

使用 PaperCode 完成一条论文任务

本页按“使用参数、运行模式、输入材料、质量调优、实时监控、恢复导出”组织，便于用户和维护者按同一条路径跑通产品。

开发者调试代码时也从这里开始：先用真实 TUI 创建一条 PaperRun，再进入开发指南定位模块。

源码启动

git clone https://github.com/ZhuchenZhong/paper_fucker.git
cd paper_fucker
bun install
bun run build
.\papercode.exe

终端最低尺寸为 96x28，推荐 120x34。窗口不足时 TUI 会显示中文尺寸提示，恢复尺寸后自动回到原页面。

使用参数

参数是否必需说明配置入口
研究目标必需自然语言主题、代码仓库目标、已有论文改写目标或实验复现目标。首页输入框。
模型池必需用户注册 provider 后，从所有可用模型中勾选候选池，再选择主/备用决策模型。/models
工作区可选不选择时运行写入用户目录；选择后把中间文件、代码和导出放入当前工作区。/folder
材料可选论文、代码、数据、实验日志和补充说明会进入 intake，并写入 source ledger。/file、/data、/log
研究深度可选快速、标准、深入、投稿和自定义，用于控制检索、实验、审稿和预算强度。Shift+Tab

三种运行模式

主题到论文 只输入研究主题。系统先做检索、查新、研究规划，再生成草稿、证据账本和审稿意见。
材料到论文 拖入论文、数据或日志。系统围绕材料抽取 claim、方法和实验事实，避免把外部结论写成未验证事实。
代码到论文 选择代码工作区。系统读取 source range，生成实验协议，执行 baseline/ablation/container 复现后再写结果。

配置模型

/models 打开全屏模型工作台。用户先注册 provider，再从可用模型中勾选候选池；候选池之外的模型不会被 PaperRun、Agent Team 或子 agent 使用。

页面用途操作
已注册显示已授权的 ChatGPT 订阅、Copilot CLI 订阅和自定义 endpoint。刷新模型、smoke、删除 provider、清空全部。
所有模型展示已注册 provider 返回的全部模型。多选候选池，设置主决策模型和备用决策模型。
全流程模型配置 planner、writer、reviewer、citation_checker、experiment 等阶段策略。自动选择、动态选择或强制指定。

选择工作区

/folder 优先打开系统目录选择器。Windows 需要能选择驱动器；原生选择器不可用时回退到中文 TUI 目录选择器。

默认 run 保存在用户目录。只有用户明确选择工作区后，才写入对应项目工作区。

输入材料

材料类型入口进入系统后的用途
论文 PDF / DOCX / Markdown/file进入文献和材料 source ledger，用于相关工作、方法对齐和引用检查。
代码仓库/folder触发代码扫描、source range、实验协议和复现证据。
数据文件/data进入数据字典、指标计算、baseline/ablation 或可视化建议。
实验日志/log进入 terminal trace、ResultReport 和 reproduction gate。

创建 PaperRun

输入示例：
我想研究 agent team 在代码实验论文生成中的应用，要求包含可复现实验设计

TUI 会把输入、当前工作区、默认期刊 profile、研究深度和材料入口传给 POST /paper/runs。创建失败时显示中文结构化诊断，包括原因、处理动作和日志路径。

质量调优

目标调法验收
论文更完整提高研究深度，补充论文材料和实验日志。章节完整，Related Work 和 References 使用 verified source。
实验更可信选择工作区，补齐 baseline、ablation、容器复现和 GPU/编译器环境。ResultReport 有真实 terminal trace，final gate 不因复现缺失阻断。
格式更稳定默认中国计算机学报 profile，先修 Markdown 结构，再修 Pandoc/LaTeX 导出。中文题名、摘要、英文摘要、关键词、正文、参考文献和附录可读。

实时 Monitor

运行中可以通过 TUI 或 /preview 打开只读 Web Monitor。它显示 stage graph、draft、source ledger、claim ledger、agent tree、cost/token、gate、export 和实验终端摘要。

  • Preview 使用 token-protected localhost URL。
  • SSE 持续接收 paper.run.snapshot 更新。
  • 写请求必须被只读阻断。

恢复与退出

TUI 使用 /resume 选择历史 run。CLI 可使用：

papercode runs list
papercode resume <run-id>

退出时展示 run id、状态、token/cost 摘要和恢复命令，方便继续任务。
