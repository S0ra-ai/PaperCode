Usage for Maintainers

从源码跑通一条 PaperRun

本页用于开发者本机验收：启动 TUI、配置模型、选择工作区、创建 PaperRun、查看实时 Monitor、导出和恢复历史任务。

它不是手册主线。主线开发入口在 开发指南，本页用于确认本机环境和用户路径是否可用。

验收口径 使用入口只记录维护者需要亲自跑通的步骤：模型、工作区、PaperRun、Preview、导出和恢复。面向代码修改的说明放在开发指南、模块地图和关键函数索引。

源码启动

git clone https://github.com/ZhuchenZhong/paper_fucker.git
cd paper_fucker
bun install
bun run build
.\paper_fucker.exe

终端最低尺寸为 96x28，推荐 120x34。低于最低尺寸时 TUI 会显示中文阻断页，恢复尺寸后回到原页面。

配置模型

入口用途验收点
/models打开全屏模型工作台。只显示用户已注册 provider；未注册 provider 不进入候选池。
已注册管理 ChatGPT 订阅、Copilot CLI 订阅、自定义 endpoint。支持删除 provider、清空全部、刷新模型和保存。
所有模型从已注册 provider 的模型中多选候选池。主决策模型和备用模型只能从候选池选。
全流程模型为 planner、writer、reviewer 等阶段设置自动、动态或强制模型。强制模型不可用时必须阻断，不静默降级。

选择工作区

/folder 优先打开原生文件夹选择器。Windows 需要支持驱动器选择；原生选择器不可用时回退中文 TUI 选择器。

默认 run 写入 ~/.paper_fucker/runs。只有用户明确选择工作区后，才写入 <workspace>/.paper_fucker/runs。

创建 PaperRun

输入示例：
我想研究 agent team 在代码实验论文生成中的应用，要求包含可复现实验设计

TUI 会把输入、当前工作区、期刊 profile、研究深度和材料入口传给 POST /paper/runs。创建失败必须返回中文结构化诊断。

实时 Monitor

运行中可以通过 TUI 或 /preview 打开只读 Web Monitor。它显示 stage graph、draft、source ledger、claim ledger、agent tree、cost/token、gate、export 和实验终端摘要。

  • Preview 使用 token-protected localhost URL。
  • SSE 持续接收 paper.run.snapshot 更新。
  • 写请求必须被只读阻断。

恢复与退出

TUI 使用 /resume 选择历史 run。CLI 可使用：

paper_fucker runs list
paper_fucker resume <run-id>

退出时展示 run id、状态、token/cost 摘要和恢复命令，方便继续任务。
