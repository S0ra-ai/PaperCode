# 测试案例

用于端到端测试报告生成功能的样例文件。

## 文件说明

| 文件 | 类型 | 用途 |
|------|------|------|
| `2020自然科学基金面上项目-正式版.docx` | 模板 | DOCX 报告模板，测试模板上传与格式化输出 |
| `Adv Funct Materials - 2025 - Ko - *.pdf` | 参考文献 | 低介电聚合物 + 高导热，铜箔基板方向 |
| `CEJ-25 Novel furfuryl-based *.pdf` | 参考文献 | 呋喃基含磷阻燃剂 + 低介电环氧树脂 |
| `CEJ-25 Surface modification *.pdf` | 参考文献 | 聚磷腈改性空心玻璃微球 + 低介电聚酰亚胺 |
| `Macromolecular Rapid Communications - 2025 - Takahashi - *.pdf` | 参考文献 | 低介电损耗聚酰亚胺开发 |
| `shi-et-al-2025-*.pdf` | 参考文献 | 聚硅氧烷低介电 + 高阻燃一步法制备 |

## 测试场景

1. **纯主题生成** — 只输入主题，不附带任何文件
2. **附件辅助生成** — 上传 PDF 参考文献，测试 RAG 本地检索链路
3. **模板驱动生成** — 上传 DOCX 模板，验证格式化输出
4. **混合模式** — 同时上传模板 + 参考文献

## 主题建议

> 低介电高分子材料的研究进展与应用前景

所有 PDF 均围绕"低介电常数 / 低介电损耗高分子材料"方向，适合作为该主题的参考文献集。
