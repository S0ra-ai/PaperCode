# 前后端交互说明文档

## 1. 概述

本文档详细描述了IntelliGen系统中前端与后端的交互方式，包括通信协议、数据格式、认证机制、主要交互流程和错误处理等。

## 3. 通信协议与数据格式

### 3.1 通信协议

- **协议**：HTTP/HTTPS
- **默认端口**：
  - 前端：根据部署环境配置（通常为80/443）
  - 后端：根据部署环境配置（通常为8080）
  - 模型策略服务：8082

### 3.2 数据格式

- **请求格式**：JSON
- **响应格式**：JSON
- **字符编码**：UTF-8

### 3.3 统一响应格式

所有API响应遵循以下格式：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    // 实际数据
  }
}
```

**字段说明**：

| 字段名 | 类型 | 必需 | 描述 |
|-------|------|------|------|
| code | Integer | 是 | 状态码，200表示成功 |
| message | String | 是 | 响应消息 |
| data | Object/Array/String | 否 | 响应数据，根据具体接口返回 |

**常见状态码**：

| 状态码 | 描述 |
|--------|------|
| 200 | 成功 |
| 202 | 正在处理中（模型策略服务或后端任务状态接口） |
| 400 | 请求参数错误 |
| 401 | 未授权，需要登录 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

## 4. 认证机制

### 4.1 认证流程

#### 4.1.1 用户登录

```
1. 前端收集用户名和密码
2. 前端调用 /auth/login 接口
3. 后端验证用户名和密码
4. 后端检查用户 `authStatus`
5. 若 `authStatus = 1`，后端生成JWT Token
6. 若 `authStatus = 0`，后端返回“管理员还未审核，请耐心等待”
7. 若 `authStatus = 2`，后端返回“账号已被禁用，请联系管理员”
8. 前端仅在登录成功时将Token存储在本地（localStorage或其他存储）
9. 后续请求在请求头中携带Token
```

#### 4.1.2 Token携带方式

所有需要认证的API请求必须在请求头中添加：

```
Authorization: Bearer {token}
```

### 4.2 Token管理

#### 4.2.1 Token存储

建议前端使用以下方式之一存储Token：

1. **localStorage**（推荐）
```javascript
// 存储
localStorage.setItem('token', token);

// 获取
const token = localStorage.getItem('token');

// 删除
localStorage.removeItem('token');
```

2. **sessionStorage**
```javascript
// 存储
sessionStorage.setItem('token', token);

// 获取
const token = sessionStorage.getItem('token');

// 删除
sessionStorage.removeItem('token');
```

#### 4.2.2 Token过期处理

当Token过期或无效时，后端会返回401状态码。前端应：

1. 清除本地存储的Token
2. 清除用户信息
3. 跳转到登录页面
4. 提示用户重新登录

### 4.3 模型策略服务认证

模型策略服务使用不同的认证方式：

1. **请求头**：`Authorization: Bearer {secretKey}`
2. **请求参数**：在请求体或查询参数中添加 `appid`

说明：模型策略服务只允许后端调用，前端不直接访问该服务。
说明：`appid` 与 `secretKey` 由后端环境变量提供，前端不保存也不透传模型凭证。

```
7. 模型策略服务执行AI任务处理
8. 前端轮询 GET /tasks/{taskId}
9. 后端查询本地任务状态，必要时向模型策略服务查询进度
10. 任务完成后返回报告内容，前端展示结果
```

## 6. 前端API调用示例

### 6.1 请求封装

```javascript
// src/api/request.js
import axios from 'axios';

// 创建axios实例
const api = axios.create({
  baseURL: 'http://localhost:8080',
  timeout: 10000,
  headers: {
    'Content-Type': 'application/json'
  }
});

// 请求拦截器
api.interceptors.request.use(
  config => {
    // 从localStorage获取token
    const token = localStorage.getItem('token');
    if (token) {
      config.headers.Authorization = `Bearer ${token}`;
    }
    return config;
  },
  error => {
    return Promise.reject(error);
  }
);

// 响应拦截器
api.interceptors.response.use(
  response => {
    const res = response.data;
    if (res.code === 200 || res.code === 202) {
      return res;
    } else {
      // 处理错误
      if (res.code === 401) {
        // 未授权，清除token并跳转登录
        localStorage.removeItem('token');
        window.location.href = '/login';
      }
      return Promise.reject(new Error(res.message || '请求失败'));
    }
  },
  error => {
    console.error('请求错误:', error);
    return Promise.reject(error);
  }
);

export default api;
```

## 7. 错误处理

### 7.1 前端错误处理策略

```javascript
// 全局错误处理
api.interceptors.response.use(
  response => {
    // 处理成功响应
    return response;
  },
  error => {
    if (error.response) {
      // 服务器返回错误状态码
      switch (error.response.status) {
        case 400:
          alert('请求参数错误');
          break;
        case 401:
          // 清除token并跳转登录
          localStorage.removeItem('token');
          window.location.href = '/login';
          break;
        case 403:
          alert(error.response.data?.message || '当前账号无权限或尚未通过审核');
          break;
        case 404:
          alert('请求的资源不存在');
          break;
        case 500:
          alert('服务器内部错误');
          break;
        default:
          alert('请求失败');
      }
    } else if (error.request) {
      // 请求发出但没有收到响应
      alert('网络错误，请检查网络连接');
    } else {
      // 请求配置出错
      alert('请求配置错误');
    }
    return Promise.reject(error);
  }
);
```

## 8. 状态管理

### 8.1 用户状态管理

```javascript
// 简单的状态管理
const userStore = {
  state: {
    userInfo: null,
    token: null,
    isLoggedIn: false
  },

  init() {
    // 从localStorage恢复状态
    const token = localStorage.getItem('token');
    const userInfo = localStorage.getItem('userInfo');
    if (token && userInfo) {
      this.state.token = token;
      this.state.userInfo = JSON.parse(userInfo);
      this.state.isLoggedIn = true;
    }
  },

  login(userInfo, token) {
    this.state.userInfo = userInfo;
    this.state.token = token;
    this.state.isLoggedIn = true;
    localStorage.setItem('token', token);
    localStorage.setItem('userInfo', JSON.stringify(userInfo));
  },

  logout() {
    this.state.userInfo = null;
    this.state.token = null;
    this.state.isLoggedIn = false;
    localStorage.removeItem('token');
    localStorage.removeItem('userInfo');
  }
};

// 初始化
userStore.init();
```

## 10. 轮询机制

### 10.1 任务状态轮询

后端 `GET /tasks/{taskId}` 对前端统一返回 camelCase 字段：`currentSection`、`totalSections`、`resultMarkdown`、`errorMessage`。即使后端内部调用模型策略服务获取到 `current_section`、`total_sections`，也需要先转换后再返回前端。

```javascript
// 轮询任务状态
export const pollTaskStatus = (taskId, onProgress, onComplete, onError) => {
  const pollInterval = 2000; // 2秒轮询一次
  let pollCount = 0;
  const maxPollCount = 300; // 最多轮询10分钟

  const poll = async () => {
    try {
      const res = await getTaskStatus(taskId);
      
      if (res.code === 200) {
        // 任务完成
        onComplete(res.data);
        return;
      } else if (res.code === 202) {
        // 任务进行中
        onProgress(res.data);
        pollCount++;
        
        if (pollCount < maxPollCount) {
          setTimeout(poll, pollInterval);
        } else {
          onError(new Error('任务超时'));
        }
      } else {
        // 其他错误
        onError(new Error(res.message));
      }
    } catch (error) {
      onError(error);
    }
  };

  // 开始轮询
  poll();
};

// 使用示例
pollTaskStatus(
  taskId,
  (progress) => {
    console.log('进度:', progress.progress, progress.currentSection, progress.totalSections);
  },
  (result) => {
    console.log('完成:', result.resultMarkdown);
  },
  (error) => {
    console.error('错误:', error);
  }
);
```

## 11. 注意事项

1. **Token安全**：
   - 不要在URL中传递Token
   - Token应存储在安全的地方
   - 定期刷新Token（如果实现了刷新机制）

2. **跨域问题**：
   - 后端需要配置CORS
   - 开发环境可使用代理解决跨域

3. **请求超时**：
   - 设置合理的超时时间
   - 处理超时错误

4. **错误提示**：
   - 提供友好的错误提示
   - 区分网络错误、业务错误等

5. **加载状态**：
   - API请求时显示加载状态
   - 防止重复提交

6. **数据缓存**：
   - 合理使用缓存
   - 及时更新缓存数据

7. **并发控制**：
   - 控制并发请求数量
   - 使用请求队列管理
