## 四、当前已知边界

这些不是主任务未完成，而是当前系统的已知边界：

### 1. Markdown 下载的定位

- `md` 下载本质上是“原始研究结果源码下载”
- 它不是网页阅读态，也不是成品文档态
- 因此不保证像网页端那样完成视觉渲染

### 2. DOCX 导出定位

- 当前 `docx` 已可用
- 常见公式、粗体、列表、换行问题已修正
- 但它仍然更偏“可交付导出”，不是“高度排版设计成品”

### 3. 本地直连模型的限制

- 如果后端仍在本地，模板/附件文件地址会受到公网可访问性限制
- 因此当前更推荐走“服务器后端联调”
