# 第三轮 DOCX 公式混合导出执行记录 - 2026-03-24

## 本次结论

在用户确认“纯图片效果并不好”之后，DOCX 公式导出从“图片优先”升级为“Word 原生公式优先，图片兜底，文本降级”的混合方案。

本次实现已完成核心切换，后端测试通过。

## 本次落地内容

1. 将 DOCX 公式插入路径从 `XmlCursor + 直接拷贝 XML` 改成 `CTP.addNewOMath()` / `CTP.addNewOMathPara()` 的 schema 原生写法。
2. 保留原有图片兜底链路，避免复杂公式或不支持公式直接失败。
3. 保留坏公式文本降级，避免单个公式拖垮整篇文档。
4. 继续维持行内公式、块级公式、表格内公式三类导出能力。
5. 保持现有测试覆盖：普通导出、常见公式、表格公式、坏公式降级、复杂公式兜底。
