# Folio Sample Gallery

Three deterministic, cassette-backed end-to-end samples — one per
builtin venue. Each is a frozen reference output regenerated by
`scripts/build_sample_gallery.py` from the matching e2e cassette.

| Demo | Venue | Language | Sections | LLM source |
|---|---|---|---|---|
| [`ieee_demo/`](ieee_demo/README.md) | IEEE Conference | en | extracted from input.pdf | DeepSeek-chat (cassette) |
| [`cjc_demo/`](cjc_demo/README.md) | Chinese Journal of Computers (CJC) | zh | builtin (8) | DeepSeek-chat (cassette) |
| [`springer_demo/`](springer_demo/README.md) | Springer LNCS | en | builtin | DeepSeek-chat (cassette) |

## Rebuild all three

```pwsh
uv run python scripts/build_sample_gallery.py
```

## Rebuild a single demo

```pwsh
uv run python scripts/build_sample_gallery.py --only cjc_demo
```

## Regression test

`tests/integration/test_sample_gallery.py` asserts each demo's
generated output is byte-equal to its `expected/` bundle, which
catches accidental drift in stage prompts or LaTeX templates.

See each demo's README for cassette-recording instructions.
